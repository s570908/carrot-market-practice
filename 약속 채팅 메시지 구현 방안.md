# 약속 채팅 메시지 구현 방안

## 질문

이 약속을 메시지 형식으로 만들어야 할 것 같다. 이 메시지가 나오면 거기에 적합한 UI 를 만들어서 제공하자. 
그리고UI의 끝 부분에 두 개의 버튼을 만들자. 하나는 약속보기 또 하나는 장소보기 를 만들자. 이 약속보기 버튼을 누르면 모달창으로 약속을 만드느 창과 유사하게 만들어서 이미 만든 약속을 보여주자. 완료버트을 누르며 모달창을 닫자.  그리고 지도는 보여 주지 말자. 오직 스트링 형삭으로만 보여 주자. 그리고 장소보기를 누르면 장소의 이미지 맵뷰를 띄워서 보여주자. 완료하면 모달 창이 사라지게 만들자. 
이것을 위해서 먼저 prisma model을 잘 구성해야 될 것 같다. 약속에 관한 모댈과 이 모델을 릴레이션으로 메시지를 연결하고 이 메시지는 약속에 관한 메시지라는 prisam 모델을 수정해야 될 것 같다. 그리고 코드를 만들어서 보여 줄때 가능한 한 기존의 코드도 보여주고 네가 추가한 부분은 코멘트를 넣어줘. 그리고 알고리즘과 개념을 자세히 설명하는 것도 잊지마. 

## 1. Prisma 모델 설계

약속 관련 데이터 모델을 `ChatMeetup`으로 구성합니다:

```prisma
// 채팅 약속 모델 추가
model ChatMeetup {
  id          Int      @id @default(autoincrement())
  date        DateTime
  time        String
  location    String
  latitude    Float?   // 지도 표시를 위한 위도
  longitude   Float?   // 지도 표시를 위한 경도

  // 메시지 관계 (양방향)
  message     SellerChat? @relation(fields: [messageId], references: [id])
  messageId   Int?        @unique  // 하나의 메시지는 하나의 약속만 가짐
  
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

// 기존 SellerChat 모델에 chatMeetup 필드 추가
model SellerChat {
  id          Int      @id @default(autoincrement())
  chatMsg     String
  user        User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  userId      Int
  chatRoom    ChatRoom @relation(fields: [chatRoomId], references: [id], onDelete: Cascade)
  chatRoomId  Int
  
  // 새로 추가된 약속 관계
  chatMeetup  ChatMeetup?
  
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

## 3. 약속 생성 페이지 수정

현재 약속 생성 페이지(create.tsx)의 `handleSubmit` 함수를 수정하여 ChatMeetup 생성 및 메시지 전송하도록 변경:

```tsx
// filepath: pages\appointment\create.tsx
const handleSubmit = async () => {
  if (!date) {
    alert("날짜를 선택해주세요.");
    return;
  }

  if (!time) {
    alert("시간을 선택해주세요.");
    return;
  }

  if (!selectedLocation) {
    alert("장소를 선택해주세요.");
    return;
  }

  try {
    // 1. ChatMeetup 데이터 생성
    const meetupResponse = await fetch("/api/chat-meetups", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        chatRoomId: chatroomId,
        date,
        time,
        location: selectedLocation.selectedAddress,
        latitude: selectedLocation.latitude,
        longitude: selectedLocation.longitude,
        alertTime
      }),
    });

    if (!meetupResponse.ok) {
      throw new Error("약속 생성에 실패했습니다");
    }

    const { chatMeetup } = await meetupResponse.json();

    // 2. 약속 메시지 전송
    await fetch(`/api/chats/${chatroomId}/messages`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        chatMsg: "약속이 생성되었습니다",
        chatMeetupId: chatMeetup.id,
      }),
    });

    // 3. 채팅방으로 리디렉션
    router.push(`/chats/${chatroomId}`);
  } catch (error) {
    console.error("약속 생성 중 오류 발생:", error);
    alert("약속 생성에 실패했습니다");
  }
};
```

## 4. API 엔드포인트 구현

### ChatMeetup API

```typescript
// filepath: pages\api\chat-meetups\index.ts
import { NextApiRequest, NextApiResponse } from "next";
import client from "@libs/server/client";
import { withApiSession } from "@libs/server/withSession";
import { withHandler } from "@libs/server/withHandler";

async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  if (req.method === "POST") {
    // ChatMeetup 생성
    const {
      body: { chatRoomId, date, time, location, latitude, longitude, alertTime },
      session: { user },
    } = req;

    if (!user?.id) {
      return res.status(401).json({ ok: false, error: "로그인이 필요합니다" });
    }

    // ChatMeetup 생성
    const chatMeetup = await client.chatMeetup.create({
      data: {
        chatRoom: {
          connect: { id: +chatRoomId },
        },
        date: new Date(date),
        time,
        location,
        latitude: latitude || null,
        longitude: longitude || null,
      },
    });

    return res.json({
      ok: true,
      chatMeetup,
    });
  }

  return res.status(405).json({ ok: false, error: "Method not allowed" });
}

export default withApiSession(
  withHandler({
    methods: ["POST"],
    handler,
    isPrivate: true,
  })
);
```

```typescript
// filepath: pages\api\chats\[id]\messages.ts
// POST 메시지 핸들러 부분 수정
if (req.method === "POST") {
  const {
    body: { chatMsg, chatMeetupId }, // chatMeetupId 추가
    session: { user },
  } = req;

  if (!user?.id) {
    return res.status(401).json({ ok: false, error: "로그인이 필요합니다" });
  }

  // 메시지 생성 시 약속 ID가 있으면 연결
  const message = await client.sellerChat.create({
    data: {
      chatMsg,
      user: {
        connect: {
          id: user.id,
        },
      },
      chatRoom: {
        connect: {
          id: +id,
        },
      },
      ...(chatMeetupId
        ? {
            chatMeetup: {
              connect: {
                id: +chatMeetupId,
              },
            },
          }
        : {}),
    },
  });

  // 생성된 메시지가 약속 메시지인 경우 ChatMeetup 업데이트
  if (chatMeetupId) {
    await client.chatMeetup.update({
      where: { id: +chatMeetupId },
      data: { messageId: message.id },
    });
  }

  return res.json({ ok: true, message });
}
```

## 5. 구현 알고리즘 설명

### 데이터 흐름

1. **약속 생성 과정**:
   - 사용자가 약속 페이지에서 날짜, 시간, 장소 입력
   - `handleSubmit` 함수 실행:
     - `ChatMeetup` 데이터 생성 (API 호출)
     - 약속 ID를 포함한 채팅 메시지 생성 (API 호출)
     - 채팅방으로 리디렉션

2. **채팅방에서 약속 표시**:
   - 메시지 목록에서 `chatMeetup` 필드가 있는지 확인
   - 약속 메시지인 경우 `ChatMeetupMessage` 컴포넌트로 렌더링
   - 일반 메시지인 경우 `Message` 컴포넌트로 렌더링

3. **약속 정보 조회**:
   - "약속보기" 버튼 클릭 → 약속 정보 모달 표시
   - "장소보기" 버튼 클릭 → 약속 장소 지도 모달 표시

### 기술적 구현 요소

1. **데이터 모델링**:
   - `ChatMeetup`과 `SellerChat` 모델 간의 양방향 관계 설정
   - 메시지에서 약속으로, 약속에서 메시지로 양방향 접근 가능

2. **UI 컴포넌트**:
   - 약속 메시지용 특별 UI 컴포넌트 구현
   - 모달을 통한 약속 상세 정보 및 지도 표시

3. **API 설계**:
   - 약속 생성 API
   - 메시지 API 확장 (약속 연결 기능)
   - 채팅 조회 API 확장 (약속 정보 포함)

### 개선 가능한 부분

1. **오류 처리**: 각 API 호출의 오류 처리 보강
2. **상태 관리**: 약속 상태(확정, 변경, 취소 등) 추가
3. **알림 기능**: 약속 시간 접근 시 알림 발송 기능 구현
4. **UI 개선**: 약속 메시지의 시각적 구분 강화

이 구현을 통해 사용자는 채팅 내에서 약속 정보를 자연스럽게 확인하고, 필요에 따라 상세 정보나 위치를 모달을 통해 볼 수 있게 됩니다.
